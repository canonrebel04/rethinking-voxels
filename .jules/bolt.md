## 2024-05-18 - Replacing generic `pow` with optimized `pow2` in GLSL
**Learning:** Found instances where `pow(x, 2)` or `pow(x, 2.0)` were being used. In GLSL, standard `pow` is typically evaluated using `exp2(y * log2(x))`, which is slower than simple multiplication. Additionally, there were instances of implicit type casting (e.g. `pow(max(0, 1 - ...), 2)`) which can cause type mismatch overhead or compilation errors in strict GLSL environments.
**Action:** When a power of 2 is needed, always use the `pow2(x)` helper function defined in `shaders/lib/common.glsl` (or just `x * x` inline). Additionally, always explicitly cast integer literals to floats (e.g. `0.0` instead of `0`) and cast variables via `float()` when passing to mathematical functions like `max()` to improve type safety.
