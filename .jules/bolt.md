## 2024-05-24 - GLSL Nested Loop Interchange
**Learning:** In GLSL shaders, when an inner loop contains expensive calculations (like trigonometry, matrix multiplications, and normalize operations) that depend solely on the inner loop's index variable, interchanging the loops can massively reduce the number of redundant computations. Additionally, using integer and float mixed variables in functions like `pow()` must be explicitly typed (e.g., casting integers with `float()`) to ensure optimal and safe evaluations. Also, extracting `pow(x, 2.0)` to local variable multiplications `t = x; t * t` prevents macro double evaluation and improves performance.
**Action:** Always verify if loop-invariant math can be hoisted or if nested loops can be interchanged to pull expensive operations outward. Always explicitly cast integers to floats when mixing types.
