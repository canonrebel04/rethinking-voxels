## 2024-05-14 - Shaderpack UX via .lang Tooltips
**Learning:** In a Minecraft shaderpack, the UI is primarily the shader settings menu. Adding user-friendly names and `.comment` descriptions to raw configuration keys in `.lang` files directly translates to in-game tooltips, significantly improving the UX for players trying to understand complex graphical settings.
**Action:** When working on shaderpacks or similar modding contexts, look for unmapped configuration properties to provide helpful localized descriptions.
