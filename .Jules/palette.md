## 2024-09-07 - Missing UI Setting Exposed
**Learning:** Orphaned configuration sliders that are implemented in the code (e.g. `VBL_STRENGTH` in Minecraft shaders) but missing from UI screens or underlying `#define` assignments can cause confusion and leave accessible tuning options hidden from users.
**Action:** When auditing configurations like `shaders.properties`, use shell scripting to extract all sliders, cross-reference them against UI mappings (like `screen.VBL_SETTINGS=...`), and define corresponding backend `#define` logic if missing to correctly expose functional options.
## 2023-10-24 - Shaderpack UX Consistency
**Learning:** In Minecraft shaderpacks, UI settings mapped in `shaders.properties` can become orphaned from their localization keys if the underlying variable name changes (e.g., `MOTION_BLURRING` to `MOTION_BLUR_EFFECT`) but the `.lang` file is not updated. Additionally, settings fully implemented in `.glsl` files with `.lang` translations (like `CONWAY` and `VOLUMETRIC_BLOCKLIGHT`) might be missing from the `shaders.properties` layout grid entirely, rendering them inaccessible to users in the GUI.
**Action:** Extract all base translation keys from `.lang` files and cross-reference them against variables in `shaders.properties` to find hidden or unmapped settings. Expose these settings by replacing `<empty>` spacers in relevant layout screens (e.g., `screen.VX_WORLD` for environment effects) and update mismatched `.lang` keys to match the active `.glsl` variable names.
